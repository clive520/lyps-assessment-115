## 🌟 系統特色與分析維度

本系統將國語文、數學、英語文三科之檢測數據進行多維度結構化整合，提供「全校 ➔ 班級 ➔ 個人」跨層級之互動式學力診斷儀表板：

```mermaid
flowchart LR
    A["🏛️ 全校宏觀觀點<br>(常模對標與體質診斷)"] --> B["🏫 班級向度診斷<br>(試題全景與錯題解構)"]
    B --> C["👤 個人微觀歷程<br>(雷達圖與客製處方)"]
    C --> D["📋 差異化分組<br>(拔尖/補救/偏科)"]
    D --> E["🖨️ 成績通知列印<br>(A4 單頁排版)"]
```

### 1. 🏛️ 全校宏觀觀點 (School Benchmark)
* **常模對標**：對標「臺中市常模」與「全國總參與常模」，三科平均表現均超越縣市與全國基準 6~7 個百分點。
* **學科等級結構**：精熟、基礎、待加強三級比例堆疊呈現。
* **全校體質診斷**：深入剖析全校優勢向度（數學解題思考 81% 超標 25%）與警訊指標（國語章法知識 48%、數學量與實測 40% 全卷最低、英語雙峰 M 型化分佈）。

### 2. 🏫 班級向度診斷 (Class Diagnostics)
* **向度差距明細**：詳細列出 26 個評量向度之題數、涵蓋題號、班級答對率、縣市標準與常模落差（Gap）。
* **試題層級深度分析 (Item Diagnostics)**：視覺化逐題答對率長條圖，呈現各題難易度。
* **TOP 5 易錯難題與迷思選項解構 (Distractor Analysis)**：分析誘答選項分佈，精準診斷全班共性迷思概念。
* **性別學力差異**：男生在數學空間與解題思考表現活躍，女生在國語篇章理解與英語聽讀表現突出。

### 3. 👤 個人微觀歷程 (Individual Student Profiles)
* **座號快捷檢索**：支援快速搜尋座號、依群組標籤快速篩選。
* **向度雷達圖 (SVG Radar Chart)**：動態展現個人各向度得分輪廓與全班平均基準線之對比。
* **專屬錯題清單**：列出該生做錯的所有題號、向度、個人選擇選項與標準答案，方便個別訂正輔導。
* **逐題作答反應矩陣**：綠色答對、紅色答錯，滑鼠懸停顯示題目資訊。

### 4. 📋 差異化分組與教學處方 (Differentiated Grouping)
* 🌟 **拔尖加深組**：三科全精熟（PR 85~99），提供高階探究與專題挑戰。
* 🚨 **關鍵補救組**：多科待加強（PR < 25），提供核心基礎概念扶助計畫。
* ⚖️ **顯著偏科組**：單科突出但單科落後（PR 落差 45+），運用強科自信牽引弱科學習。
* 📘 **穩健精進組**：班級中堅主力，加強題目審題細緻度與弱項突圍。

### 5. 🖨️ 成績通知單列印中心 (Print Center)
* 專門針對 A4 直式列印優化排版，支援一鍵列印全班（自動每人一張 A4）或個別列印。
* 內建 CSV 資料匯出功能，方便教師進行進一步資料統計。
